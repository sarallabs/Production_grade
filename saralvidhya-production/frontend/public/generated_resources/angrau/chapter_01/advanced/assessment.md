**Depth Level:** L-3

**Difficulty:** Hard  

**Question:** Which statement correctly distinguishes Type I from Type II Peritrophic Membranes in insects?
- A) Type I PM is shed during ecdysis; Type II PM is permanent.
- B) Type I PM is secreted along the entire midgut epithelium; Type II PM is produced continuously by an anterior ring organ (cardia).
- C) Type I PM contains chitin; Type II PM consists solely of lipids.
- D) Type I PM is restricted to sap-feeders; Type II PM occurs only in wood-borers.

<details><summary>Click to view Answer</summary>Correct Answer: B<br>Rationale: Type I PM is delaminated from midgut epithelial cells throughout the midgut; Type II PM is secreted as a continuous sleeve by the anterior cardia.</details>
