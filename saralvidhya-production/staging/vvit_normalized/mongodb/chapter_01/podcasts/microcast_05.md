This is the brief on MongoDB query filtering, projection, and cursor pagination. For VVIT B.Tech CSE students, we are breaking down how MongoDB filters documents with comparison and logical operators, shapes returned fields with projection, and paginates large result sets using the sort, skip, and limit pipeline.

First, when filtering beyond exact equality, MongoDB uses dollar-prefixed comparison operators inside the query document: $gt and $gte for greater than, $lt and $lte for less than, $ne for not equal, and $in or $nin to match against an array of candidate values. You can combine multiple conditions using $and, $or, $not, and $nor. Second, the second parameter of find(query, projection) controls which fields are returned: use 1 to include fields and 0 to exclude fields. You cannot mix inclusion and exclusion in the same projection, with one critical exception: the _id field is always included by default unless you explicitly suppress it with _id: 0.

Finally, cursor modifiers let you paginate results using sort({ field: 1 | -1 }), where 1 is ascending and -1 is descending, along with skip(n) and limit(n). No matter what order you chain them in mongosh, MongoDB's query engine always executes sort first, then skip, and finally limit to guarantee deterministic pagination across pages.
