# Computational Thinking & Problem Solving

Computational thinking is an iterative methodology for understanding problems and formulating solutions that can be effectively carried out by an information-processing agent.

## Core Pillars
1. **Decomposition**: Breaking down a complex problem into manageable components.
2. **Pattern Recognition**: Identifying similarities and recurring sequences.
3. **Abstraction**: Filtering out non-essential details to focus on core mechanics.
4. **Algorithm Design**: Constructing step-by-step instructions for a repeatable solution.
