## 3. Architecture & Verification Standards

- **Acoustic Normalization**: All audio files undergo pre-flight downsampling to 16 kHz mono 32kbps MP3 matching Whisper's native acoustic filterbank, guaranteeing 100% upload compliance under Groq's 25 MB payload ceiling.
- **Zero-Hallucination Calibration**: Groq Whisper inferences execute with `temperature=0.0`, ensuring deterministic verbatim transcription without repetitive hallucinations.
- **Synchronized Subtitles**: Every audio file includes an exact millisecond-accurate SubRip (`.srt`) stream ready for instant import into LMS video players or web players.
- **Machine Manifest**: The `.json` artifacts provide programmatic access for downstream RAG pipelines, Flashcard generators, and Bloom's taxonomy assessment tools.
