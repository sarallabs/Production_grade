# Study Guide: Scientific Study

## Key Learning Objectives
1. Identify independent, dependent, and controlled variables in any scientific experiment.
2. Differentiate between fundamental and derived units, and write down their compositions.
3. Perform unitwise analysis to test the validity of physical equations.

## Core Concepts & Formulas

### Variables Identification Rule
- Ask yourself: *"What am I changing?"* $\rightarrow$ **Independent Variable**
- Ask yourself: *"What am I measuring or observing?"* $\rightarrow$ **Dependent Variable**
- Ask yourself: *"What must remain exactly the same to keep the test fair?"* $\rightarrow$ **Controlled Variables**

### Derived Units Table
| Quantity | Formula | Base Units | Derived Unit Name |
| :--- | :--- | :--- | :--- |
| Area | $l \times b$ | $m^2$ | Square meter |
| Volume | $l \times b \times h$ | $m^3$ | Cubic meter |
| Density | $\text{Mass} / \text{Volume}$ | $kg/m^3$ | $kg/m^3$ |
| Velocity | $\text{Displacement} / \text{Time}$ | $m/s$ | Meter per second |
| Acceleration | $\text{Velocity} / \text{Time}$ | $m/s^2$ | Meter per second squared |
| Force | $\text{Mass} \times \text{Acceleration}$ | $kg\cdot m/s^2$ | Newton (N) |
| Pressure | $\text{Force} / \text{Area}$ | $kg/(m\cdot s^2)$ | Pascal (Pa) |
| Work | $\text{Force} \times \text{Distance}$ | $kg\cdot m^2/s^2$ | Joule (J) |
| Power | $\text{Work} / \text{Time}$ | $kg\cdot m^2/s^3$ | Watt (W) |

### Unitwise Analysis Example
To check if $v^2 = u^2 + 2as$ is valid:
- LHS unit: $(m/s)^2 = m^2 s^{-2}$
- RHS units:
  - $u^2 \rightarrow (m/s)^2 = m^2 s^{-2}$
  - $2as \rightarrow (m/s^2) \times m = m^2 s^{-2}$
Since both sides have the unit $m^2 s^{-2}$, the equation is **valid**.
