# Points to Remember — Scientific Study

- **Variables:** Causative factor (independent), effect (dependent), and constants (controlled).
- **Fundamental Units:** 7 base quantities (m, kg, s, K, A, cd, mol).
- **Derived Units:** Made from combining base units (e.g., $N$, $Pa$, $J$).
- **Equation Verification:** Base units on LHS must equal base units on RHS.
