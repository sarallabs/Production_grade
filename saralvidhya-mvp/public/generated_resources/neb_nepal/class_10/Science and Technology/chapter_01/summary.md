# Quick Summary — Scientific Study

## 1. Variables in Scientific Research
Scientific research investigates the relationships between different factors called **variables**. A variable is any characteristic, trait, or physical quantity that can change.
- **Independent Variable:** The variable manipulated or changed by the researcher (the cause). There should be only one in an experiment.
- **Dependent Variable:** The variable observed and measured for changes (the effect). There should be only one in an experiment.
- **Controlled Variable:** All other factors kept constant throughout the experiment to ensure a fair and valid test.

## 2. Measurement Units
Physical quantities are measured using standard units, classified into:
1. **Fundamental Units:** Independent units that cannot be simplified further. The SI system has 7 base units:
   - Length: meter (m)
   - Mass: kilogram (kg)
   - Time: second (s)
   - Temperature: kelvin (K)
   - Electric Current: ampere (A)
   - Luminous Intensity: candela (cd)
   - Amount of Substance: mole (mol)
2. **Derived Units:** Units formed by combining two or more fundamental units (e.g., Area: $m^2$, Force: Newton ($N = kg\cdot m/s^2$), Pressure: Pascal ($Pa = kg/(m\cdot s^2)$)).

## 3. Unitwise Equation Analysis
Equations and formulas are validated by ensuring that the fundamental units on both sides of the equation are identical.
- Addition and subtraction of physical quantities are only possible if they have the same base unit composition (e.g., $u + v$ is valid, but $s + at$ is invalid).
