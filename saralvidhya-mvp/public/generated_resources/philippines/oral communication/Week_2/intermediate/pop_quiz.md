### Question 1: Categorizing Complex Speech Acts
During a national emergency, an official broadcast announces: *"Typhoon Signal No. 3 is active over the province. Evacuation is strictly mandatory for coastal residents before 6:00 PM."* Which two communicative functions are simultaneously operating?
- [ ] A) Social Interaction and Phatic Communion
- [x] B) Information Dissemination and Control / Regulation
- [ ] C) Emotional Expression and Poetic Language
- [ ] D) Metalingual Definition and Grooming Talking

> **Explanation**: The broadcast disseminates objective meteorological data (Information Dissemination) while enforcing mandatory evacuation orders backed by civil authority (Control / Regulation).

### Question 2: Karl Bühler's Organon Model (1934)
Karl Bühler categorized language functions from the standpoint of Plato's grammatical persons. Which function corresponds to the **First Person (Addresser-Oriented)**?
- [ ] A) Conative Function
- [ ] B) Representational Function
- [x] C) Expressive Function
- [ ] D) Metalingual Function

> **Explanation**: The Expressive Function reveals the speaker's inner psychological state, subjective mood, and personal feelings (First Person / *"I"*).

---

### Question 3: Roman Jakobson's Six Factors (1960)
When a webinar speaker pauses and asks: *"Can the audience in the back rows hear my audio clearly?"*, which of Jakobson's communicative functions is being utilized?
- [ ] A) Poetic Function
- [ ] B) Referential Function
- [x] C) Phatic Function
- [ ] D) Conative Function

> **Explanation**: Jakobson's Phatic function focuses on the **Contact / Channel**, serving to verify, prolong, check, or terminate the communicative connection.

---

### Question 4: The Metalingual Function
Which of the following statements represents Roman Jakobson's **Metalingual Function**?
- [ ] A) *"It is very hot in this auditorium today."*
- [x] B) *"What do you mean by the term 'phatic communion'?"*
- [ ] C) *"Please submit your project portfolios by Friday."*
- [ ] D) *"The speed of light in a vacuum is approximately 300,000 km per second."*

> **Explanation**: The Metalingual function uses language to discuss, define, clarify, or explain the linguistic code itself.

---

### Question 5: James Britton's Transactional Role
In James Britton’s (1970) functional model, what role does a speaker assume when using the **Transactional Function**?
- [x] A) A participant role (using language as an instrument to get things done, inform, or persuade)
- [ ] B) A spectator role (contemplating aesthetic and poetic beauty)
- [ ] C) A passive listener role
- [ ] D) An exclusively ritualistic role

> **Explanation**: Britton's transactional function involves an active participant role aimed at getting things done in practical and civic life.

### Question 6: Overlapping Functions in a State of the Nation Address (SONA)
Why does a President's State of the Nation Address (SONA) represent an overlapping functional cluster?
- [ ] A) Because political speeches are not governed by functional theories
- [x] B) Because it simultaneously reports state achievements (Information), inspires civic solidarity (Motivation), and issues executive policy directives (Control)
- [ ] C) Because nonverbal channels cancel out spoken words
- [ ] D) Because it is limited strictly to phatic communion

> **Explanation**: Complex institutional discourse naturally blends information dissemination, regulatory mandates, and inspirational motivation to fulfill governance goals.

### Question 7: Commercial Signage in the Linguistic Landscape
A commercial billboard displays the slogan: *"Iba ang May Pinagsamahan"* (*San Miguel Beer*), showing a group of close friends laughing together. What primary communicative function does this commercial sign deploy?
- [ ] A) Control / Regulation
- [x] B) Motivation and Social Interaction
- [ ] C) Scientific Information Dissemination
- [ ] D) Metalingual Definition

> **Explanation**: The slogan appeals to cultural camaraderie, long-standing friendship, solidarity, and belonging to motivate brand loyalty.

### Question 8: Desmond Morris's Ethological Model (1967)
In *The Naked Ape*, ethologist Desmond Morris compared human polite small talk to primates picking fleas off each other. What did he name this functional category?
- [ ] A) Information Talking
- [ ] B) Mood Talking
- [ ] C) Exploratory Talking
- [x] D) Grooming Talking

> **Explanation**: Morris coined "Grooming Talking" to describe polite, meaningless social chatter used by humans to establish peaceful coexistence and mutual trust.

### Question 9: Conflict Resolution with "I" Statements
Which of the following demonstrates an effective **"I" Statement** for resolving an interpersonal misunderstanding?
- [ ] A) *"You always mess up the presentation because you never listen to me!"*
- [x] B) *"I feel anxious when presentation slides are edited at the last minute because it disrupts our rehearsal flow."*
- [ ] C) *"Why are you so lazy and irresponsible?"*
- [ ] D) *"You need to fix your attitude right now."*

> **Explanation**: "I" statements express personal feelings and specific behaviors without resorting to personal attacks or accusatory labels.

### Question 10: The Role of Nonverbal Cues in Control/Regulation
Which set of nonverbal behaviors most strongly reinforces the **Control / Regulation** function of communication?
- [ ] A) Slouching shoulders, whispering, and looking down at the floor
- [x] B) Direct eye contact, erect posture, authoritative vocal tone, and raised hand gesture
- [ ] C) Giggling, playful nudging, and sitting close to the listener
- [ ] D) Yawning, stretching, and looking repeatedly at a wrist watch

> **Explanation**: Authoritative posture, firm vocal delivery, direct eye contact, and formal uniforms project legitimate authority and reinforce regulatory compliance.
