# Formative Assessment: Functions of Communication & Language Models (Intermediate Level)

## 📝 Intermediate Evaluative Assessment

Evaluate your grasp of communicative functions, extrinsic language models, the Philippine linguistic landscape, and conflict remediation strategies.

---

### Question 1
During a national health crisis, the Department of Health issues an official broadcast: *"Face masks are mandatory in all enclosed public transit vehicles. Violators will face a fine of 1,000 pesos."* Which two communicative functions are simultaneously operating?
- [ ] A) Social Interaction and Motivation
- [x] B) Control / Regulation and Information Dissemination
- [ ] C) Emotional Expression and Phatic Communion
- [ ] D) Poetic and Metalingual Functions

> **Explanation**: The announcement conveys objective legal guidelines (Information Dissemination) while mandating specific public behavior backed by penalties (Control/Regulation).

---

### Question 2
Karl Bühler’s (1934) Organon Model links functions of language to grammatical persons. Which function corresponds to the **First Person (Addresser-Oriented)**?
- [ ] A) Conative Function
- [ ] B) Representational Function
- [x] C) Expressive Function
- [ ] D) Metalingual Function

> **Explanation**: The Expressive Function externalizes the inner mood, emotional state, and subjective perspective of the speaker (First Person / *"I"*).

---

### Question 3
In Roman Jakobson’s (1960) six-factor framework, which communicative function is oriented specifically toward the **Contact / Channel** factor?
- [ ] A) Poetic Function
- [x] B) Phatic Function
- [ ] C) Referential Function
- [ ] D) Conative Function

> **Explanation**: The Phatic function verifies, prolongs, or terminates the physical and psychological connection between interlocutors (e.g., *"Hello? Can you hear me?"*).

---

### Question 4
A teacher tells an anxious student preparing for a national debate: *"You possess exceptional critical thinking skills, and your arguments are solid. Trust your preparation and command that stage tomorrow!"* What is the primary function?
- [ ] A) Control / Regulation
- [x] B) Motivation
- [ ] C) Information Dissemination
- [ ] D) Phatic Communion

> **Explanation**: The teacher is inspiring, encouraging, and building confidence in the student to persevere and succeed.

---

### Question 5
James Britton (1970) identified three functional roles in language development. In which role does a speaker use language as a **spectator** to create or appreciate verbal art?
- [ ] A) Transactional Function
- [ ] B) Expressive Function
- [x] C) Poetic Function
- [ ] D) Pragmatic Active Function

> **Explanation**: Britton's Poetic function places the user in a spectator role, creating contemplated verbal art and aesthetic literature.

---

### Question 6
An advertisement on EDSA features a billboard reading: *"Walang Iwanan sa Pamilyang Pilipino"* (*No One Gets Left Behind in the Filipino Family*), displaying an image of smiling coworkers sharing coffee. What primary communicative function does this commercial sign deploy?
- [ ] A) Control / Regulation
- [x] B) Motivation and Social Interaction
- [ ] C) Information Dissemination
- [ ] D) Metalingual Definition

> **Explanation**: The advertisement leverages cultural solidarity, emotional belonging, and social camaraderie to motivate brand loyalty.

---

### Question 7
In interpersonal conflict resolution, which technique is most effective at preventing defensive escalation?
- [ ] A) Using absolute words like *"You always"* or *"You never"*
- [x] B) Using constructive "I" statements that frame the issue around personal feelings and specific actions
- [ ] C) Interrupting the other speaker to correct their facts immediately
- [ ] D) Walking away silently without giving feedback

> **Explanation**: "I" statements express personal impact without attacking the listener’s character, fostering collaborative problem-solving.
