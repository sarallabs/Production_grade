# Underlying Price (S)

> **Sub-Topic 2.3.1:** Five Variables | **Chapter:** Derivatives Options | **Level:** Beginner

--- 

### 📝 Source Institutional Content
> **Reference:** Page 3
> **Content:** Underlying Price (S): S rises -> Call Value rises, Put Value falls.

--- 

### 📋 Summary View
- **Concept:** The actual price of the stock (underlying) directly impacts the option price. Call options rise when the stock price rises; Put options rise when it falls.
- **Analogy:** The size of a tree directly determines the length of its shadow.
- **Key Takeaway:** The stock price is the main engine of option value.

### 🔍 Detailed View
**Explanation:** Since options derive value from the underlying asset, any movement in the stock price causes immediate changes in the option premium.
**Worked Example:** If Infosys stock price rises from ₹1,500 to ₹1,550, the premium of an Infosys ₹1,500 Call option will rise (e.g., from ₹40 to ₹80), while the premium of an Infosys ₹1,500 Put option will fall (e.g., from ₹35 to ₹5).
