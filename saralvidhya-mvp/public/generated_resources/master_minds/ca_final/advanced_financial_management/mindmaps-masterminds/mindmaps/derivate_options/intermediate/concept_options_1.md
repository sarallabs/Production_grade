# Option

--- 

### 📋 Summary View
- **Concept Summary:** An option is a derivative contract providing the buyer the unilateral right, but not the obligation, to execute a transaction in an underlying asset at a pre-specified strike price within a given timeframe.
- **Formula/Rule:** Standard guidelines apply.
- **Application Context:** No specific application context available.

### 🔍 Detailed View
**Explanation:** Options are classified as non-linear derivatives because their payoff does not move in a 1:1 ratio with the underlying. The buyer pays an upfront premium to the seller (writer). The premium consists of Intrinsic Value (current real value) and Extrinsic Value (time value and volatility value).
**Worked Example:** A stock trades at ₹1,520. A Call option with a strike price of ₹1,500 costs ₹45. The intrinsic value is ₹20 (₹1,520 - ₹1,500), and the time value (extrinsic value) is ₹25 (₹45 - ₹20).
