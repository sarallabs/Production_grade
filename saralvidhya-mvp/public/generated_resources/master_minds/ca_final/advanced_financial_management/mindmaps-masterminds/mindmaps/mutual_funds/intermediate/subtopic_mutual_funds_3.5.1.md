### 📋 Summary View

- **Concept Summary:** Measures the risk-adjusted excess return per unit of total risk (Standard Deviation).

- **Formula/Rule:** Standard guidelines apply.

- **Concept Summary:** The excess return of a portfolio over its expected return predicted by the Capital Asset Pricing Model (CAPM).

### 🔍 Detailed View

#### 🔸 Sharpe Ratio
**Formula:**
$$S_p = \frac{R_p - R_f}{\sigma_p}$$
Where:
$R_p = \text{Portfolio Return}$
$R_f = \text{Risk-Free Rate}$
$\sigma_p = \text{Standard Deviation of Portfolio Returns (Total Risk)}$
**Worked Example:**
Fund A Return ($R_p$) = 15%
Risk-Free Rate ($R_f$) = 6%
Standard Deviation ($\sigma_p$) = 12%
$$S_p = \frac{15\% - 6\%}{12\%} = $\frac{9\%}{12\%} = 0.75$$
*Interpretation:* Fund A generates 0.75% of excess return for every 1% of total risk taken.

#### 🔸 Treynor Ratio
**Formula:**
$$T_p = \frac{R_p - R_f}{\beta_p}$$
Where:
$\beta_p = \text{Beta of the Portfolio (Systematic Risk)}$
**Worked Example:**
Fund B Return ($R_p$) = 16%
Risk-Free Rate ($R_f$) = 6%
Portfolio Beta ($\beta_p$) = 1.25
$$T_p = \frac{16\% - 6\%}{1.25} = $\frac{10\%}{1.25} = 8.0\% \text{ (or 0.08)}$$
*Interpretation:* Fund B generates 8% excess return for every unit of market-related systematic risk.

#### 🔸 Jensen's Alpha
**Formula:**
$$\alpha_p = R_p - [R_f + \beta_p(R_m - R_f)]$$
Where:
$R_m = \text{Market/Benchmark Return}$
**Worked Example:**
Fund C Return ($R_p$) = 18%
Risk-Free Rate ($R_f$) = 6%
Portfolio Beta ($\beta_p$) = 1.1
Benchmark Return ($R_m$) = 14%
First, calculate expected return via CAPM:
$$\text{Expected Return} = 6\% + 1.1 \times (14\% - 6\%) = 6\% + 1.1 \times 8\% = 14.8\%$$
Now, calculate Alpha:
$$\alpha_p = 18\% - 14.8\% = +3.2\%$$
*Interpretation:* The fund manager outperformed the risk-adjusted market benchmark by 3.2% through active selection.
