# Jensen's Alpha

> **Sub-Topic 3.5.1:** Ratios | **Chapter:** Mutual Funds | **Level:** Intermediate

--- 

### 📝 Source Institutional Content
> **Reference:** Page 11
> **Content:** Jensen's Alpha: Difference between actual return and expected return (CAPM). Measures manager skill. Positive alpha = outperformance.

--- 

### 📋 Summary View
- **Concept Summary:** The excess return of a portfolio over its expected return predicted by the Capital Asset Pricing Model (CAPM).
- **Formula/Rule:** Standard guidelines apply.
- **Application Context:** No specific application context available.

### 🔍 Detailed View
**Formula:**
$$\alpha_p = R_p - [R_f + \beta_p(R_m - R_f)]$$
Where:
$R_m = \text{Market/Benchmark Return}$
**Worked Example:**
Fund C Return ($R_p$) = 18%
Risk-Free Rate ($R_f$) = 6%
Portfolio Beta ($\beta_p$) = 1.1
Benchmark Return ($R_m$) = 14%
First, calculate expected return via CAPM:
$$\text{Expected Return} = 6\% + 1.1 \times (14\% - 6\%) = 6\% + 1.1 \times 8\% = 14.8\%$$
Now, calculate Alpha:
$$\alpha_p = 18\% - 14.8\% = +3.2\%$$
*Interpretation:* The fund manager outperformed the risk-adjusted market benchmark by 3.2% through active selection.
