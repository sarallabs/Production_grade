# Treynor Ratio

> **Sub-Topic 3.5.1:** Ratios | **Chapter:** Mutual Funds | **Level:** Intermediate

--- 

### 📝 Source Institutional Content
> **Reference:** Page 11
> **Content:** Treynor Ratio: Excess return per unit of systematic risk (Beta). Assumes diversified portfolio.

--- 

### 📋 Summary View
- **Concept Summary:** Measures the risk-adjusted excess return per unit of systematic risk (Beta).
- **Formula/Rule:** Standard guidelines apply.
- **Application Context:** No specific application context available.

### 🔍 Detailed View
**Formula:**
$$T_p = \frac{R_p - R_f}{\beta_p}$$
Where:
$\beta_p = \text{Beta of the Portfolio (Systematic Risk)}$
**Worked Example:**
Fund B Return ($R_p$) = 16%
Risk-Free Rate ($R_f$) = 6%
Portfolio Beta ($\beta_p$) = 1.25
$$T_p = \frac{16\% - 6\%}{1.25} = $\frac{10\%}{1.25} = 8.0\% \text{ (or 0.08)}$$
*Interpretation:* Fund B generates 8% excess return for every unit of market-related systematic risk.
