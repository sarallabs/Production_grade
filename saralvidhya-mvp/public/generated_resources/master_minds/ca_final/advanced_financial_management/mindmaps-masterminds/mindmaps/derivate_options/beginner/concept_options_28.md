# European Exercise Terms

> **Sub-Topic 2.5.1:** Assumptions | **Chapter:** Derivatives Options | **Level:** Beginner

--- 

### 📝 Source Institutional Content
> **Reference:** Page 3
> **Content:** European exercise terms.

--- 

### 📋 Summary View
- **Concept:** The model assumes that the options can only be exercised on the final day of expiration (European style).
- **Analogy:** Assuming a voucher can only be redeemed on December 31st, rather than any day before it.
- **Key Takeaway:** The model doesn't account for early exercise flexibility.

### 🔍 Detailed View
**Explanation:** Because BSM uses a single fixed time-to-expiry date, it cannot accurately price American-style options (which can be exercised early). Fortunately, Indian index options are European-style, so the model fits them well.
**Worked Example:** If you are pricing an American option on a stock where the buyer might exercise early to capture a dividend, the BSM formula will undervalue the option because it ignores this early exercise benefit.
