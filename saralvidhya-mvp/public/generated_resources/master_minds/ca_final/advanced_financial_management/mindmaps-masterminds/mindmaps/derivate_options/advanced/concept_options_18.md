# Strike Price (X)

> **Sub-Topic 2.3.1:** Five Variables | **Chapter:** Derivatives Options | **Level:** Advanced

--- 

### 📝 Source Institutional Content
> **Reference:** Page 3
> **Content:** Strike Price (X): X rises -> Call Value falls, Put Value rises.

--- 

### 📋 Summary View
- **Strategic Context:** **Concept Summary:** The strike price is the contractually locked execution price. It determines whether an option is In-the-Money (ITM), At-the-Money (ATM), or Out-of-the-Money (OTM).
**Key Takeaway:** Strike price determines the intrinsic threshold of the option.
**Analogy:** A retail discount coupon. A coupon locking a price of ₹1,000 is more valuable than one locking it at ₹1,500.
- **Quantitative Model:** No specific quantitative model details.
- **Risk/Opportunity:** No specific risk/opportunity details.

### 🔍 Detailed View
**Explanation:**
Call Option: ITM if $S > X$; ATM if $S \approx X$; OTM if $S < X$.
Put Option: ITM if $S < X$; ATM if $S \approx X$; OTM if $S > X$.
Higher strike prices reduce Call values and increase Put values.
**Worked Example:** Nifty is at 22,100.
22,000 CE is ITM (has ₹100 intrinsic value, premium is high, e.g., ₹220).
22,100 CE is ATM (has ₹0 intrinsic value, premium is moderate, e.g., ₹130).
22,200 CE is OTM (has ₹0 intrinsic value, premium is low, e.g., ₹60).
