# Sharpe Ratio

> **Sub-Topic 3.5.1:** Ratios | **Chapter:** Mutual Funds | **Level:** Intermediate

--- 

### 📝 Source Institutional Content
> **Reference:** Page 11
> **Content:** Sharpe Ratio: Excess return per unit of total risk (Standard Deviation).

--- 

### 📋 Summary View
- **Concept Summary:** Measures the risk-adjusted excess return per unit of total risk (Standard Deviation).
- **Formula/Rule:** Standard guidelines apply.
- **Application Context:** No specific application context available.

### 🔍 Detailed View
**Formula:**
$$S_p = \frac{R_p - R_f}{\sigma_p}$$
Where:
$R_p = \text{Portfolio Return}$
$R_f = \text{Risk-Free Rate}$
$\sigma_p = \text{Standard Deviation of Portfolio Returns (Total Risk)}$
**Worked Example:**
Fund A Return ($R_p$) = 15%
Risk-Free Rate ($R_f$) = 6%
Standard Deviation ($\sigma_p$) = 12%
$$S_p = \frac{15\% - 6\%}{12\%} = $\frac{9\%}{12\%} = 0.75$$
*Interpretation:* Fund A generates 0.75% of excess return for every 1% of total risk taken.
